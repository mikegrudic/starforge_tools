Getting the code
----------------

STARFORGE simulations are run with the STARFORGE development branch of GIZMO:

.. code:: bash

   git clone -b starforge_dev https://github.com/pfhopkins/gizmo.git

Note that although the repository is publicly accessible, the development code is not free to use for any purpose - see the `GIZMO documentation <http://www.tapir.caltech.edu/~phopkins/Site/GIZMO_files/gizmo_documentation.html>`__ for the code's use policies.
